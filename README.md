# AZLAN — Web Application Security Auditing Platform

AZLAN is a production-grade, zero-cost-core web application security auditing platform for developers.

## Product loop
Audit → Understand → Fix → Verify

## Zero-cost core
The core requires only open-source/local software. No paid API, cloud account, hosted LLM, or proprietary security service is required.
